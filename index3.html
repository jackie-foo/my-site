Design notes

What this concept is doing

01 / Entry

The first prompt lowers the barrier to participation. Instead of forcing a full reply, the interface offers feelings, emojis, and small response handles.

02 / Interpretation

Suggested replies are visible and editable, which helps the chatbot feel supportive rather than controlling. The user can borrow language without being trapped by it.

03 / Repair

Each loop leaves room for clarification, correction, and softer re-entry. That makes the experience more suitable for uncertain, emotional, or high-friction communication moments.

This page is set up as a polished visual concept. It already loops on its own, and later you can swap the staged interaction for a real demo capture or connect it to a live prototype flow.
